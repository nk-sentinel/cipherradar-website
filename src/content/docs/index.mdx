## What is CipherRadar?

CipherRadar scans source code, containers, and config files to produce a
**CycloneDX 1.7 Cryptography Bill of Materials (CBOM)** — a structured inventory of every
algorithm, protocol, certificate, and piece of key material in your software. It maps those
findings to compliance frameworks and flags what's vulnerable to quantum attack.

No build required. No source leaves your machine. One binary.

## 60-second start

```bash
# Build the CLI
cd cli && go build -o cradar ./cmd/cradar

# Scaffold config, then scan
cradar init
cradar scan ./my-app -o cbom.json --validate

# Gate a pipeline on policy
cradar policy check cbom.json --policy policy.cradar.yml --fail-on high
```

Head to the [CLI Overview](/guides/cli/overview/) for installation and the full quick start,
or jump to the [CBOM Output Schema Reference](/guides/cli/cbom-schema-reference/) to learn how
to read the output.
